# 共享网盘平台(FileBrowser + frp 多站点)

> 一套自建的"多网盘"平台:**一台有公网 IP 的云服务器(47)作入口,多台个人电脑各自跑一个独立网盘**,彼此隔离、共享同一个公网入口。
> 自己用 537G 大网盘、也拉朋友上车(朋友电脑跑他自己的网盘,数据留在各自本地)。
> **本仓库是完整配置存档 + 部署文档 + 一键脚本 + 计网学习笔记,不含真实密码/IP(全部占位)。**

---

## 一、现在长什么样(一次看懂)

```
                     朋友A电脑(独立网盘,数据在它本地)
                          │ frpc 隧道
云服务器 47(公网入口) ──────┼── 朋友B电脑(独立网盘)
  nginx:8081(main 网盘)    │
  nginx:8082…(各新站)      └── 你电脑(main:E:\NetDist 537G 老网盘)
  frps/fbproxy/pan-web(门户)
```

- **站主(owner)= 你**:管所有站点 + 你的大网盘;通过 **网页门户**发邀请码/启停站/作废邀请码。
- **每个站点 = 一台电脑上的 FileBrowser**:数据存在那台电脑,完全独立(独立 db/隧道/账号)。
- **guest**:各站主人用网页给自己朋友开的只读号。

## 二、访问入口与账号(当前实例)

| 入口 | 地址 | 账号 | 说明 |
|---|---|---|---|
| **站主门户** | `http://<SERVER_IP>:8089` | owner | 管站点/发邀请码/下载安装包(经公网;详见 docs/07) |
| **主网盘 main** | `http://<SERVER_IP>:8081` | admin 或 guest | 你最大那份网盘(数据 E:\NetDist) |
| 各朋友站 | `http://<SERVER_IP>:8082…` | 各站自己的 admin/guest | 由 install-site 自动分配端口 |

> 密码/凭据在服务器本地 `runtime\fbwin\凭据-本地备忘.txt`(被 git 忽略,不入库)。

## 三、日常怎么用(速查)

- **自己存文件**:放进 `E:\NetDist\公共\`(朋友能下)或 `E:\NetDist\私人\`(只自己)。
- **拉一个新朋友开网盘**(全程 ~5 分钟):
  1. 门户「发新邀请码」→ 复制 `PAN-xxx`;
  2. 把 `pan-install.zip`(在 main 网盘 `公共\` 或门户下载)+ 邀请码发给朋友;
  3. 朋友:解压 → 双击 `install-site.bat` → 输 47 地址 / 邀请码 / 选个空文件夹 / 设密码 → 自动装好,得到他自己的网址。
- **给朋友开只读 guest**:朋友登录自己网盘 → ⚙设置 → 用户 → 新增(目录范围填 `/公共`,只勾"下载")。
- **指针(不复制挂载外部文件)**:网盘根 `管理工具\指针助手.bat` → 支持挂文件/文件夹、可到任意子目录、可列出/删除(符号链接,不复制数据)。
- **启停网盘**:网盘根 `管理工具\启动网盘.bat / 停止网盘.bat / 查看状态.bat`。
- **电脑开机 = 网盘在线**:服务开机自启、断线自动重连、大文件断点续传内置。

## 五、关键组件速查(部署在 47)

| 组件 | 作用 | 位置 |
|---|---|---|
| nginx | 对外反代 | 8081 主站;8089 门户 redeem;各站 8082.. |
| frps | frp 服务端 | `/usr/local/bin/frps`(站1 legacy 走 443;多站各自端口) |
| fbproxy.py | 登录去空格(每站一个) | `/srv/fbproxy.py <listen> <backend>` |
| pan-web.py | owner 门户 + 一次性邀请码 | `/usr/local/bin/pan-web`(127.0.0.1:9100 → 公网 8089) |
| pan-ctl | 站主 CLI(add/rm/ls/stop/start/reset-token) | `/usr/local/bin/pan-ctl` |
| 注册表/邀请/owner 密码 | root 私有 | `/etc/frp-sites/` |

## 七、安全与边界(请读)

- 数据经 frp 隧道流经 47 **但不落盘**;各站内容在各自电脑,站间四层隔离(端口/frps/token/db)。
- **站主无法删除别人站的 guest**(那些数据在朋友电脑)——朋友自己网页管。
- 门户/各网盘当前为**明文 HTTP**(登录有强口令);HTTPS 为待办(见 docs/07 与 records)。
- 仓库**不含真实凭据**:运行实例在 `runtime/`(git 忽略),发布前做过敏感词扫描。真实密码只在 `runtime\fbwin\凭据-本地备忘.txt`。
- 版权内容注意:分发的破解软件/影片属敏感内容,公开仓库仅保留脱敏配置与文档。

## 八、从零复现(想自己搭一套)

1. 读 `docs/05`(主站单机)+ `docs/06`(多站)+ `docs/07`(产品化);
2. 47 上装 frps/nginx/python,部署 `pan-ctl` + `pan-web.py` + `fbproxy.py`;
3. 客户端跑 `install-site.bat`(或手动 `deploy-site.ps1`)即可得到自己的网盘;
4. 打开 47 系统防火墙 ufw 放行对应端口(云控制台 + 服务器内 ufw 双层都要!见 docs/06 踩坑)。
