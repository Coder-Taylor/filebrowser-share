# 给朋友的使用说明（guest）

## 怎么进

浏览器打开分享给你的网址，用下面账号登录：

- 账号：`guest`
- 密码：`（找分享的人要）`

## 能做什么

- 看 `公共/` 下的电影和软件，**下载**
- 只读：不能上传、不能改名、不能删——放心看就行

## 下载注意两点

1. **单个文件**：勾选它（点文件行首的方框，计数变成 1）→ 点右上角 ⬇ → 下载的是**原文件**，不用解压。比如电影 mp4、安装包 exe、iso 都这么下。
2. **文件夹 / 一次选多个**：会先弹"选压缩格式"，选 **zip** 就行 → 下载得到一个 `.zip` → **本地解压**后内容和网盘上一模一样（无损）。
   > 为什么文件夹要打包？因为一次网络下载只能传输"一个文件"，文件夹里有很多文件，服务器必须先合成一个压缩包。这是所有网盘的通例。

## 看下载进度（还剩多少）

进度条是**浏览器**管的，不在网盘页面上。下载时按 **`Ctrl + J`** 打开浏览器的下载列表，就能看到**百分比和剩余时间**：

- Chrome / Edge：`Ctrl+J`（或点下载箭头 → 显示全部）
- 手机浏览器一般也有"下载管理"入口

## 看不了 / 转圈怎么办

- 确认用的是 Chrome、Edge、Firefox 这类浏览器，别在微信/QQ 内置浏览器里直接下大文件
- 换个网络（校园网/手机热点）再试大文件
