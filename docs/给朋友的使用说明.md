# 给朋友的访问说明(网盘访客视角)

> 实际展示文件见主站 `公共/使用说明.txt`(此模板保持同步,脱敏,不含真实账号/IP)。

## 登录
- 网址:`http://<SERVER_IP>:8081`
- 账号/密码:站主**私发给你**的那一组(只读号)。前后多了空格也能登录,系统自动忽略;忘记密码找站主重置。

## 能看什么 / 怎么下载
- 登录后看到「公共」,内容由站主放(电影/剧集/软件等),可看可下载,**只读**(不能改/删/上传)。
- 下载:选中文件 → 顶部「⬇ 下载」→ 原文件;进度看浏览器下载列表 `Ctrl+J`。

## 下载中断了怎么办
- 浏览器下载列表点「恢复」→ 从断点继续;
- 常断就用 Motrix / IDM / 迅雷(自动断点续传);
- 文件夹打包(zip)中断不能续传,大文件逐个单文件下。

## 想开一个"自己的网盘"?(当站长,可选)
1. 登录后下载 `公共/pan-install.zip`;
2. 解压 → 双击 **install-site.bat**(UAC 点是);
3. 填 `47 地址 <SERVER_IP>` / 邀请码(找站主,一人一次)/ 一个空文件夹 / 自设 ≥12 位密码;
4. 约 30 秒后得到自己的网盘网址,自己网页里给朋友开只读号。

## 提示
- 网盘只在站主电脑开机时在线;打不开 = 没开机,晚点再试。
- 大文件(2~3G)下载要几分钟到十几分钟,正常。
