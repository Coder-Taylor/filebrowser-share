# 给朋友的使用说明（guest）

## 怎么进

浏览器打开分享给你的网址，用下面账号登录：

- 账号：`guest`
- 密码：`（找分享的人要）`

## 能做什么

- 看 `公共/` 下的电影（老友记 4K 全季）和软件包，**下载**
- 只读：不能上传、不能改名、不能删——放心看就行
- 容量很大（500G+），目录里放了什么就能下什么

> ⚠️ 网盘由分享者的个人电脑提供，**只有他开机时在线**。打不开就说明电脑没开，过会儿再试。

## 下载注意三点

1. **单个文件**：勾选它（点文件行首的方框）→ 点右上角 ⬇ → 下载的是**原文件**，不用解压。比如电影 mp4、安装包 exe、iso 都这么下。2~3G 一集的 4K 视频在网速好时约十几分钟。
2. **下载中断了怎么办**：打开浏览器下载列表（`Ctrl+J`），找到中断的下载点**「恢复」**——会从断点继续，不会从头开始。若频繁断，用支持断点续传的下载器（Motrix / IDM / 迅雷）打开下载链接更稳。
3. **文件夹 / 一次选多个**：会打包成 zip 下载（无损），但**这种打包下载中断后不能续传**，需要重新下。大文件请一个个单独下载，别用文件夹打包。

## 看下载进度（还剩多少）

进度条是**浏览器**管的，不在网盘页面上。下载时按 **`Ctrl + J`** 打开浏览器的下载列表，就能看到**百分比和剩余时间**：

- Chrome / Edge：`Ctrl+J`（或点下载箭头 → 显示全部）
- 手机浏览器一般也有"下载管理"入口

## 看不了 / 转圈怎么办

- 确认用的是 Chrome、Edge、Firefox 这类浏览器，别在微信/QQ 内置浏览器里直接下大文件
- 换个网络（校园网/手机热点）再试大文件
