# 02 · 部署与配置

> 前提：一台云服务器（本文示例 40G 系统盘），装好 Docker 与 nginx。

## 1) 启动 FileBrowser 容器

见 `config/filebrowser-docker.txt`。要点：

```bash
docker run -d --name filebrowser --user root \
  -v /srv/alist/storage:/srv \
  -v /srv/fb:/database \
  -p 8085:80 --restart always \
  filebrowser/filebrowser:latest
```

## 2) nginx 反代（对外 8081）

```bash
cp config/nginx-site.conf /etc/nginx/sites-available/pan
ln -s /etc/nginx/sites-available/pan /etc/nginx/sites-enabled/pan
nginx -t && systemctl reload nginx
```

## 3) fbproxy 登录空格过滤器

```bash
cp config/fbproxy.py /srv/fbproxy.py
```

systemd 服务 `/etc/systemd/system/fbproxy.service`：

```ini
[Unit]
Description=FileBrowser login trim proxy
After=network.target docker.service

[Service]
ExecStart=/usr/bin/python3 /srv/fbproxy.py
Restart=always
RestartSec=3

[Install]
WantedBy=multi-user.target
```

```bash
systemctl daemon-reload && systemctl enable --now fbproxy
# 验证：ss -ltn 应看到 127.0.0.1:8086
```

## 4) 初始化管理员 & 目录

```bash
# 首次启动容器后，FileBrowser 默认 admin/admin，先改密码
docker stop filebrowser
docker run --rm --entrypoint filebrowser -v /srv/fb:/database --user root \
  filebrowser/filebrowser users update admin --password '<你的强密码>' --locale zh-cn -d /database/filebrowser.db
docker start filebrowser

# 在网盘根 /srv/alist/storage 建顶层目录：公共/  私人/
```

## 5) 建只读 guest 并锁定 scope

见 `config/filebrowser-users.txt`。核心是 `--scope /公共` + 关闭全部写权限，这样 guest 只能看 `公共/`。

## 6) 开放安全组端口

在云厂商安全组放行 **8081**（TCP）。8085/8086 只在服务器内网回环，不需要对外开放。

## 7) 安全提醒

- 部署完成后，用 guest 与 admin 分别登录验证隔离；
- admin 强密码，guest 弱一点无所谓（只读），但别用同一密码；
- 若用域名 + HTTPS 更佳（本项目当前为 IP:8081 明文，按需后续加证书）。
