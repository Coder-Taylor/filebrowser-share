# 01 · 架构说明

> 2026-09-06 起:**FileBrowser 主服务迁移到本地 Windows(E:\NetDist),47 仅保留为公网入口(frps + nginx + fbproxy)**。详见 docs/05。本文档拓扑为迁移后现状;迁移前的"47 上跑 FileBrowser 容器"见操作记录与 docs/02(历史部分已不适用)。

## 拓扑

```
朋友 / 自己(浏览器)
      │  http://<SERVER_IP>:8081
      ▼
47 轻量(入口,不存网盘数据)
   nginx :8081
      │
      ├── POST /api/login ──────────► fbproxy.py(127.0.0.1:8086)
      │                                   │ 用户名/密码 strip 首尾空格
      │                                   ▼
      │                            frps 数据口 8087(隧道出口)
      │
      ├── GET /static/assets/i18n-C0UlxgXD.js → /srv/fb-custom/*.js(已改中文补丁,no-cache)
      │
      └── 其余 ──► proxy_pass 127.0.0.1:8087 ─► frps(公网 443)
                                                  │ frp 隧道(tcp, token 认证)
                                                  ▼
   本地 Windows(NSSM: FileBrowserSvc + FrpcSvc,自动启动)
      frpc ──► filebrowser.exe -a 127.0.0.1 -p 8085 -r E:\NetDist -d filebrowser.db
```

## 关键流程与结论(实测)

1. **登录去空格**:nginx 把 `/api/login` 指到 fbproxy(8086),strip 后再转发 8087 → 隧道 → 本地 FileBrowser。实测带空格用户名密码登录成功。
2. **强制中文**:登录后界面 locale=zh-cn 存 db(随 db 迁移);登录前页面由 nginx alias 返回补丁版 i18n 资产(`/srv/fb-custom/`,本地 FileBrowser 保持 2.63.23 时 hash 文件名一致)。
3. **公私隔离**:guest scope=`/公共`(E:\NetDist\公共 作为其可见根),越权访问 scope 外路径返回 404(实测公网链路 404)。
4. **下载 / 断点续传**:
   - 单文件 → `/api/raw/` 源格式直接下载;**支持 HTTP Range(实测 206 Partial Content + Accept-Ranges)**,浏览器/下载工具可断点续传;
   - 多选/文件夹 → 服务器流式打包 zip 再下发,不支持 Range,断了重来 —— 大文件分享一律单文件形态;
   - 下载进度在浏览器下载页(Ctrl+J)。
5. **断链自愈**:frpc `loginFailExit=false` + NSSM 崩溃重启;实测 frps 中断 8s 后 frpc ~5s 自动重连,续传拼接数据与源文件 md5 一致。
6. **速度**:朋友下载受**本地网络上行**限制(校园网实测 4.3MB/s);47 的 200M 带宽只作为入口管道,数据不落 47 盘。
