# 01 · 架构说明

## 拓扑

```
朋友 / 自己（浏览器）
      │  https / http :8081
      ▼
   nginx  （对外 8081，sites-enabled/pan）
      │
      ├── POST /api/login ─────────────► fbproxy.py（127.0.0.1:8086）
      │                                      │ 用户名/密码 strip 首尾空格
      │                                      ▼
      │                             FileBrowser（127.0.0.1:8085）
      │
      ├── GET /static/assets/i18n-C0UlxgXD.js  →  /srv/fb-custom/*.js（已改中文补丁）
      │
      └── 其余全部 ──────────────────► FileBrowser（127.0.0.1:8085，容器）
                                          │ -v /srv/alist/storage:/srv   ← 网盘根
                                          │ -v /srv/fb:/database         ← sqlite
                                          ▼
                                    磁盘 /srv/
```

## 关键流程与结论（实测）

1. **登录去空格**：nginx 把 `/api/login` 单独指到 fbproxy(8086)，fbproxy 解析 JSON、对 `username`/`password` 做 `.strip()` 后再转发 FileBrowser(8085)。解决"账号/密码复制时带了空格"登不上的问题。
2. **强制中文**：
   - 登录后界面：FileBrowser 用户/全局 `locale = zh-cn`（注意不是 `zh`）；
   - 登录前页面：FileBrowser 前端用浏览器 `navigator.language` 探测语言，无视服务端配置 → 用补丁把探测值改成 `"zh-cn"`（见 03 篇）。
3. **公私隔离**：guest 的 scope = `/公共`。FileBrowser 按 scope 限定可见根路径；直接访问 scope 之外的路径（如 `/私人`）返回 404。
4. **下载**：
   - 单选一个文件 → 前端走 `/api/raw/<路径>`，浏览器**源格式直接下载**（已实测：返回头 `Content-Type: application/octet-stream`，字节数与源文件一致）；
   - 多选 / 文件夹 → 前端弹"压缩格式"，服务器打包成一个文件再下发（流式），下载后需解压（无损）。
5. **下载进度**：FileBrowser 把下载交给浏览器原生下载器，进度（百分比/剩余时间）在浏览器下载页看（Chrome/Edge 按 `Ctrl+J`），网页本身不画进度条。
