# 03 · 强制简体中文补丁

问题拆成两层：

| 界面 | 语言来源 | 解决方式 |
|------|----------|----------|
| 登录后（文件列表等） | FileBrowser 用户/全局 `locale` | 设为 `zh-cn`（服务端配置，永久生效） |
| 登录前（登录页） | 前端读浏览器 `navigator.language` | 打补丁强制返回 `"zh-cn"` |

**坑**：FileBrowser 简体中文 key 是 `zh-cn`，不是 `zh`（填 `zh` 会退回英文）。

## 1) 服务端 locale = zh-cn

```bash
docker stop filebrowser
docker run --rm --entrypoint filebrowser -v /srv/fb:/database --user root \
  filebrowser/filebrowser config set --locale zh-cn --branding.name '共享网盘' -d /database/filebrowser.db
docker run --rm --entrypoint filebrowser -v /srv/fb:/database --user root \
  filebrowser/filebrowser users update admin --locale zh-cn -d /database/filebrowser.db
# guest 同理 users update guest --locale zh-cn
docker start filebrowser
```

## 2) 登录前页面：改 i18n 前端资产

现象：登录页仍是英文，因为 FileBrowser 前端 `Cm()` 用 `navigator.language`（浏览器语言）决定语言，**无视服务端配置**。

做法（对运行中的网页资产打补丁 + nginx 固定返回补丁版）：

```bash
# a) 从运行中的网页下载该语言包（文件名带 hash，先看页面里引用了哪个）
mkdir -p /srv/fb-custom
curl -s http://127.0.0.1:8085/static/assets/i18n-C0UlxgXD.js -o /srv/fb-custom/i18n-C0UlxgXD.js

# b) 备份 + 替换语言探测为固定 zh-cn
cp /srv/fb-custom/i18n-C0UlxgXD.js /srv/fb-custom/i18n-C0UlxgXD.js.orig
perl -pi -e 's/navigator\.language\.toLowerCase\(\)/"zh-cn"/g' /srv/fb-custom/i18n-C0UlxgXD.js

# c) nginx 对该文件做 alias（见 config/nginx-site.conf 的 FB_CUSTOM_ZH 块）
#    alias /srv/fb-custom/i18n-C0UlxgXD.js;  +  Cache-Control: no-cache
nginx -t && systemctl reload nginx
```

效果：登录前也显示简体中文。注意文件名里的 hash 随 FileBrowser 版本变化，升级后需重做一次（这也是本项目锁定镜像版本的原因之一）。

## 验证

```bash
curl -s http://127.0.0.1:8081/static/assets/i18n-C0UlxgXD.js | grep -c 'zh-cn'   # 应命中
# 打开浏览器无痕窗口访问登录页应为中文
```
