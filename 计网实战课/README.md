# 计网实战课 · 从零学计算机网络(用 FileBrowser 网盘当教材)

> 一边用真实在跑的共享网盘(本地存储 + frp 内网穿透 + HTTP 断点续传)做实例,一边从零学计网。
> 每课一个主题,由浅入深、可独立读;文末带自测。

## 怎么用

- 按顺序读(01→09)地基最稳;
- 每课尽量**对照本网盘动手验证**(命令见 09 课);
- 有疑问回到对应课,或让 AI 用本仓库实例展开细讲。

## 课程地图

| # | 课 | 核心 | 对应本网盘的"活教材" |
|---|---|---|---|
| 01 | [数据包与分层](01-数据包与分层.md) | 包、信封(头部)、MTU/MSS、封装分层 | 2.6G 电影切成 1460B×178 万个包 |
| 02 | [TCP 三次握手与可靠传输](02-TCP三次握手与可靠传输.md) | 握手、序号/ACK/重传/窗口 | frpc↔frps 建隧道;下载一字不差 |
| 03 | [HTTP 报文与状态码](03-HTTP报文与状态码.md) | 请求/响应、状态码、Token | 200/206/401/403/404/500/502 全见过 |
| 04 | [NAT 与内网穿透](04-NAT与内网穿透.md) | 公私 IP、NAT、中继 vs 打洞 | 电脑没公网 IP、frp 隧道原理 |
| 05 | [端口与 Socket 长连接](05-端口与Socket长连接.md) | socket、监听/连接、四元组、心跳 | 一个 8081 服务几千人 |
| 06 | [断链自愈与断点续传](06-断链自愈与断点续传.md) | 自动重连 × Range 续传 × md5 | 实测:断 8s→5s 自愈→md5 一致 |
| 07 | [带宽、上下行、码率与无线](07-带宽上行与无线.md) | 瓶颈链路、码率、无线抖动 | 朋友下载 ≈ 你的上行 |
| 08 | [网络安全入门](08-网络安全入门.md) | 认证/授权/加密、攻击面、明文风险 | NAT 隐身 vs 47 暴露、404 藏私人 |

## 读完能带走的能力

- 说清"一次下载怎么从 E 盘到朋友磁盘",穿过寻址/NAT/TCP/HTTP/带宽每一层;
- 看得懂状态码与网络报错,知道从哪一层下手排查;
- 理解内网穿透、断点续传、自愈这些"工程能力"背后的协议原理。
