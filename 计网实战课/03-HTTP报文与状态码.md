## 本课主题:HTTP

### 一、HTTP 是什么?

HTTP = HyperText Transfer Protocol,一套**双方事先约好的说话格式**。FileBrowser(服务器)与浏览器(客户端)用它一问一答。"协议"= 规矩:我按 `方法 路径 版本` 问,你按 `版本 状态码` 答。守规矩就能对话。

### 二、一次对话 = 请求报文 + 响应报文

**请求**(浏览器 → FileBrowser):
```
GET /api/raw/老友记/第1集.mp4 HTTP/1.1     ← 请求行:方法 路径 版本
Host: 47.94.146.53:8081                     ← 头部 键:值
Range: bytes=1048576-2097151                ← 要哪一段(断点续传)
X-Auth: eyJhbGciOiJIUzI1NiIs...             ← 我是谁(token)
                                              ← 空行
(请求体:GET 通常无;POST 登录才有)            ← 体
```

**响应**(FileBrowser → 浏览器):
```
HTTP/1.1 206 Partial Content                ← 状态行:版本 状态码 原因
Content-Range: bytes .../2615192587         ← 头部
Content-Type: application/octet-stream
Content-Length: 1048576
                                              ← 空行
(响应体:那 1MB 视频字节)                     ← 体
```

记三点:报文 = 「行 + 头部(键:值) + 空行 + 体」;请求关键是**方法+路径**、响应关键是**状态码**;头里放元信息(长度/类型/身份/要哪段),体里只放数据。

### 三、状态码 = 服务器一句话结果,分五类

| 码段 | 含义 | 本项目实例 |
|---|---|---|
| 1xx | 进行中 | 少见 |
| 2xx | ✅ 成功 | 200、206 |
| 3xx | 跳转 | 301/302 |
| 4xx | ❌ 你的问题 | 401/403/404 |
| 5xx | ❌ 服务器问题 | 500/502 |

**逐个本项目见过的讲透(重点区分)**:

- **200 OK**:成功。health 返回 `{"status":"OK"}`、登录成功。
- **206 Partial Content**:成功但只给了你要的那一段 → Range 命中,带 `Content-Range`。
- **401 Unauthorized**:"你没证明你是谁"——没带/过期 token(日志里 `/api/renew: 401`)。
- **403 Forbidden**:"知道你是谁但没资格"——密码错、guest 想上传。
- **404 Not Found**:"不存在"——也用于**防越权伪装**:guest 访问 `/私人`,服务器故意回 404 而非 403,以免暴露"私人区存在"。隐藏不该让你知道的存在,是安全惯例。
- **500 Internal Server Error**:"服务器内部炸了"(处理链接时内部异常)。
- **502 Bad Gateway**:"代理(nginx)联系不上后端"——隧道断、frpc 没连时你看到的那页 nginx 就是 502。

**一句话分 401/403/404**:401=你谁啊(没身份证);403=你是谁也不行(没资格);404=不存在/我不告诉你存不存在。

### 四、HTTP 无状态 + Token 怎么记住你

HTTP 无状态:服务器不记得上次对话,每个请求独立。网盘要"你登录过",靠 **Token**:

```
① POST /api/login 带账号密码 → 验证 → 回一个签名 token
② 之后每请求带 X-Auth: <token> → 服务器验 token 即知"是你"
```

token = 服务器签名过的"通行证"。登录那次的空格由 fbproxy 帮忙擦掉再转发(中间件思维)。

## 带走三句话

1. HTTP 是浏览器与服务器的**对话格式**:请求(方法+路径+头)+ 响应(状态码+头+体);
2. 状态码第一位定大类:**2 成功 / 3 跳转 / 4 你的错 / 5 服务器错**;401(没认证)、403(没权限)、404(隐藏)、502(代理连不上后端)要分清;
3. 状态/身份不靠 HTTP 记,靠 **Token** 通行证每次携带。
