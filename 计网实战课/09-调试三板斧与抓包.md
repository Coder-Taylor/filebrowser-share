# 计网实战课 · 第九课:调试三板斧与抓包(动手课)

> 配套:第三课(HTTP/状态码)。本课给"网络问题怎么排查"的方法论 + 命令,全部在本项目可复现。

## 一、三板斧:分层定位

网络问题别瞎猜,按"从里到外/从具体到整体"逐层试:

**① 连通性在不在(网络层)**:主机/端口通不通
```bash
# 通不通(不是网页,是 TCP 能不能连上)
curl.exe -v --connect-timeout 5 http://<SERVER_IP>:8081/health
# Windows 也可:Test-NetConnection <SERVER_IP> -Port 8081
```

**② 协议层对不对(传输/应用)**:通但错 → 看状态码/响应
```bash
curl.exe -s -o NUL -w "%{http_code}\n" http://127.0.0.1:8085/health
# 200 = 本地 FileBrowser 好;502 见 ③
```

**③ 后端在不在(代理/隧道)**:502 = 代理连不上后端
- nginx 能回 502,说明 nginx 活着但 8087(frps)没通 → 查 frpc 是否连着(隧道)。
- 一层一层往回退:公网 → 47 → frps → 隧道 → frpc → 本地 filebrowser。

## 二、常用诊断命令(项目版)

```bash
# 服务与进程
sc query FileBrowserSvc FrpcSvc          # 本地 Windows 服务状态
ssh <47> systemctl status frps fbproxy nginx   # 47 端服务

# 端口监听
ss -ltn | grep -E '443|808[157]'          # 谁在听(47)

# 隧道日志(排查重连/认证)
# Windows: runtime\fbwin\logs\frpc-svc.out.log
# 47:      journalctl -u frps --no-pager -n 20

# 协议测试
curl.exe -s -D - -H "Range: bytes=0-99" <下载URL>   # 看是否 206(断点续传)
curl.exe -s -o /dev/null -w "%{http_code}\n" <url>  # 只要状态码

# 一次性下载测试 + 测速
curl.exe -s --range 0-52428799 -o NUL -w "speed: %{speed_download}\n" <url>
```

## 三、抓包:眼见为实(Wireshark)

Wireshark 把线路上的包"拍照"下来,是学计网最强的工具。要点:

- 过滤:**tcp.port==8081**(只看网盘)、`http`、`tcp.flags.syn==1`(看握手)。
- 能看见的真相:
  - **三次握手**:第 1 个包 SYN、第 2 个 SYN+ACK、第 3 个 ACK——亲眼看第二课;
  - **206 续传**:请求带 `Range:`,响应 206 + Content-Range;
  - **明文 HTTP**:HTTP 请求里直接能看到 token/内容 → 亲眼看"为什么说明文危险"(第八课);
  - 断链/重连:中间没有 ACK → 超时重传 → 重新 SYN。
- 本地抓包:抓 `127.0.0.1`(回环)需要在 Wireshark 里用 Npcap 的回环支持/或用 "Adapter for loopback"。

## 四、日志 = 服务器自己的"抓包"

FileBrowser 日志每行都有料(本项目真实例子):
```
/私人: 404 221.176.157.249        ← 越权访问(guest 探私人的痕迹)
/api/renew: 401 …                  ← token 过期续期失败
…AcrobatDC….msp … connection forcibly closed  ← 上传被掐断
/health 200                        ← 健康
```
学会**从日志反推状态码与行为**,是排障基本功。

## 五、排查套路(背下来)

```
打不开?
  ① curl health 公网:502? → 隧道/后端
     health 200? → 是页面/登录问题 → 看 401/403/404
  ② 本地 127.0.0.1:8085 health:不通 → filebrowser 服务死了 → 拉起来
  ③ 隧道:frpc 日志有 start proxy success?没有 → 47 443 通不通、token 对不对
  ④ 一层层往上,永远先确定"哪一段断了",再动手。
```

## 带走三句话

1. 网络排障 = **分层定位**:连通 → 协议 → 后端,一层层收窄;
2. curl 是万能探针(状态码 + Range 测试),日志是服务器自述;
3. Wireshark 抓包让你"看见"握手、206、明文——学计网必练。

## 动手练习(在本项目做)

- 停本地 FileBrowserSvc,curl 公网 health,观察 502;
- 用 curl 带 Range 头下载,看 206 与 Content-Range;
- 用 Wireshark 抓一次下载,数出三次握手与 ACK 包。
