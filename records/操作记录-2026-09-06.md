> 本次主题:**网盘主服务从 47 迁移到本地 Windows(E:\NetDist 大容量仓库),47 改为纯公网入口(frp 隧道)**。

## 背景

- 本地 E:\NetDist 有 ≈537G 内容(老友记全季 4K + 软件包,5177 个文件),47 轻量 40G 盘装不下
- 决定:FileBrowser 主服务跑本地,47 保留 nginx/fbproxy/i18n 补丁 + frps 当入口;访问地址与账号不变

## 47 侧操作

- 部署 `frps` v0.71.0(/usr/local/bin + /etc/frp/frps.toml + systemd,Restart=always)
- nginx `pan` 站点:`location /` 回源 8085(Docker 容器)→ 8087(frp 数据口);`/api/login`→fbproxy 与 i18n alias 两条规则不动
- `fbproxy.py`:BACKEND 8085→8087、转发 Host 头同步;重启
- 备份 db(`/srv/fb/filebrowser.db`)→ 本地;旧 filebrowser 容器 `--restart=no` + stop(数据留 /srv 冷备)
- **踩坑**:阿里云轻量控制台后加的防火墙规则(TCP 7000、换 7500 亦然)显示"已启用"但外网/手机流量均不通;系统预置 443 正常 → frp 控制端口改用 **443**(详见 docs/05)

## 本地 Windows 侧操作

- 目录:网盘根 `E:\NetDist` 建顶层 `公共/`(移入 Software installation package、老友记,补 使用说明.txt)与 `私人/`(空)
- 运行目录 `D:\Tools\fbwin\`:filebrowser.exe(2.63.23,db 为 47 拷贝,账号/guest scope/zh-cn 全保留)、frpc.exe(0.71.0,frpc.toml `loginFailExit=false`)
- filebrowser 监听 127.0.0.1:8085,root=E:\NetDist
- NSSM 注册 `FileBrowserSvc` + `FrpcSvc`(Automatic + 崩溃 5s 重启)

## 实测验证(全链路,浏览器→47:8081→隧道→本地)

- guest 带空格用户名密码登录成功(去空格链路 OK);登录页中文补丁生效
- guest scope=/公共:越权访问 `/私人` → 404
- **单文件下载 Range 支持**:`Range: bytes=1048576-2097151` → `206 Partial Content` + `Content-Range: …/2615192587`
- **断链自愈**:停 47 frps 8s 重启,frpc ~5s 自动重连;断前/断后两段下载拼接后与源文件 **md5 一致**
- 下载速度实测 ≈4.3MB/s(校园网上行瓶颈,预期内)
